# UniversCivilization: Empire at War Campaign Bible

`UniversCivilization: Empire at War` reframes Arklight as a space RTS/4X campaign about rival civilizations fighting for a collapsed gate lattice. The player commands fleets, colonies, ground armies, orbital stations, research programs, espionage cells, and alliance politics across twelve acts.

## Core Factions

| Faction | Role | Visual and Gameplay Identity |
|---|---|---|
| Arklight Directorate | Player command structure | Blue-white fleet doctrine, balanced economy, adaptive starships, modular colonies |
| Solar Union | Diplomatic industrial bloc | Defensive stations, shields, trade convoys, alliance voting power |
| Red Sector Compact | Militarized frontier empire | Heavy armor, mass artillery, reactor weapons, fast ground invasions |
| Dawn Concord | Scientific republic | Sensors, drones, precision strikes, jump-gate engineering |
| Eclipse Order | Covert separatist network | Stealth fleets, sabotage, psionics, black-market shipyards |
| Desert Expanse Clans | Harsh-world survival coalition | Mobile bases, resource extraction, raiders, rugged armor |
| Void Lattice | Ancient machine intelligence | Autonomous stations, gravity weapons, replication swarms, endgame threats |

## Campaign Structure

Each act contains five playable mission anchors. Chapter bands reserve room for briefing, exploration, diplomacy, side objectives, hero events, and procedural 4X incidents between missions.

## Mission Design Pillars

- RTS battles resolve ground bases, orbital shipyards, resource fields, and tactical objectives in real time.
- 4X layers decide what fleets, research, officers, defenses, and colonies are available before each mission.
- MMORPG-style commanders provide persistent traits, equipment, reputation, guild/alliance rank, and story choices.
- Fleet combat uses original starships, weapons, armor, shields, drones, missiles, stations, and carrier wings from the stellar asset manifest.
- Story choices alter diplomacy, unlock side chapters, and change the ending state without requiring copied franchise lore.
