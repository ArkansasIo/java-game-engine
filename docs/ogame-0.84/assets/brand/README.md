# UniversCivilization Brand Assets

This folder contains the sci-fi RTS/4X visual identity pass for **UniversCivilization: Empire at War**.

## Assets

| Asset | Purpose |
|---|---|
| `universcivilization-key-art.png` | Generated 16:9 logo/key art for README, launcher, splash, and store-page mockups. |
| `universcivilization-emblem.svg` | Scalable orbital crown/stargate emblem for icons, buttons, and documentation. |
| `universcivilization-wordmark.svg` | Scalable horizontal wordmark for docs, menu mockups, and UI headers. |
| `../stellar/stellar-asset-concept-sheet.png` | Original concept sheet for units, ships, buildings, weapons, armor, planets, VFX, and UI icons. |

## Palette

| Token | Hex | Usage |
|---|---|---|
| Deep space | `#040e1e` | Backdrops and shell screens |
| Panel blue | `#344566` | OGame-style panels and framed menu surfaces |
| Frame line | `#415680` | Borders, dividers, and grid lines |
| Pale command text | `#E6EBFB` | Primary UI text |
| Tactical blue | `#6DA8FF` | Selection, focus, holographic detail |
| Command lime | `#00FF00` | Ready, owned, positive state |
| Alliance green | `#33CC00` | Friendly/federation state |
| Warning gold | `#FFD25A` | High-value alerts and objective highlights |
| Hostile red | `#FF4A4A` | Enemy, invalid, critical state |

## Direction

- Use original or newly generated sci-fi assets only; do not copy proprietary browser-game, RTS, 4X, film, or licensed art.
- Prefer orbital grids, planets, fleet silhouettes, command panels, scanner lines, and deep-space blue chrome.
- Keep UI dense and operational, closer to strategy command software than a marketing splash screen.
