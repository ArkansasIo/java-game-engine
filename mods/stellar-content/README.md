# UniversCivilization Managed Content Clone

This folder is the original-content replacement workspace for the managed install content.

It mirrors the intent of `ra-content`, `cnc-content`, `d2k-content`, `ts-content`, and `common-content`, but it is not a copy of those licensed install archives. It defines original sci-fi MMORPG/4X content packages for UniversCivilization:

- `stellar-base-interface`: blue OGame-style command UI, cursor, chrome, and resource-strip art.
- `stellar-colony-buildings`: colony, economy, storage, research, defense, and shipyard structures.
- `stellar-fleet-starships`: probes, fighters, cruisers, colony arks, dreadnoughts, transports, recyclers, and expedition craft.
- `stellar-units-characters`: commanders, engineers, marines, drones, envoys, agents, and class equipment.
- `stellar-planets-terrain`: planets, moons, asteroids, orbital zones, nebula fields, and colony surfaces.
- `stellar-weapons-armor-vfx`: rail, plasma, ion, missile, shield, warp, debris, and battle-report effects.
- `stellar-campaign-media`: 12-act campaign briefings, chapter art, faction screens, loading art, and event panels.

Generated concept art currently lives at `../stellar/assets/renders/concept/ogame-scifi-4x-asset-sheet.png`.
