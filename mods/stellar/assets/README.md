# Stellar Runtime Assets

Original UniversCivilization space RTS/4X assets target this directory. See ../../../docs/ogame-0.84/stellar-asset-pipeline.md and ../../../docs/ogame-0.84/stellar-asset-manifest.yaml for the production manifest.

## Managed Content Clone

The legacy install-content categories are cloned into `../stellar-content` as original UniversCivilization content groups. The clone does not copy proprietary RTS install archives or browser-game art. It maps the same engine needs into a new sci-fi MMORPG/4X asset set:

- base files -> blue command UI, shell chrome, cursors, fonts, and core interface art
- tilesets -> orbital, asteroid, ice, lava, nebula, and colony-world terrain sets
- music and speech -> original ambient command, fleet, diplomacy, war, and discovery audio packs
- campaigns and movies -> illustrated 12-act briefing, chapter, faction, and event media
- effects and support files -> shields, warp entry, beams, missiles, debris, resources, and status icons

The first generated visual target is `renders/concept/ogame-scifi-4x-asset-sheet.png`.
